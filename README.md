# Computer Architecture & Hardware Design Sandbox

A personal repository for tracking practice problems, examples, and projects related to computer architecture

## Tools & Environments

The code in this repository is tested and simulated using various toolchains:

* **Ripes**: Visualizing the processor datapath, pipeline hazards, and hardware-level execution.
* **RARS**: Executing standard RISC-V assembly with system calls and console output.
* **CPUlator**: Web-based compilation and simulation for C and assembly.
* **RISC-V GNU Toolchain**: Cross-compiling C code to RISC-V architectures (`RV32IM`, `RV32GC`).
